# JJReader · P0.6 / 0.1.6-p0

Android-прототип для проверки EPUB и Edge TTS. Основа — существующий проект `fantadrom/JJReader`, исходный commit `62bac7e`. На Honor ABR-LX1 / Android 15 пользователь подтвердил для P0.1 открытие, прокрутку, переходы, независимость копии, наблюдаемый процент и первое звучание обоих голосов. Выявлены сбои шрифта, пометок, восстановления после пересоздания, подсветки и повторного TTS. На code 3 пользователь подтвердил шрифт, пометки, достаточное приблизительное восстановление, Светлану с подсветкой и остановку при Home/блокировке. Дмитрий успешно синтезировал два блока; третий оборвался с SocketException неизвестной причины. На code 4 подтверждены ширина landscape, шрифт, Светлана/подсветка и Пауза/Home/блокировка. Выявлены возврат к старой пометке после перехода в другой раздел и три handshake Дмитрия без аудио. На code 5 возврат к x1 сохранился, а новый ресурс в landscape снова становился узким. Без кеша Дмитрий дал служебные сообщения без аудио, Светлана успешно синтезировалась/воспроизводилась. На code6 ширина ресурсов прошла Honor, оба голоса на current прозвучали; обычный Дмитрий также заработал. Трасса позиции показала accepted restore без ACK, затем блокировку capture и сохранение старого якоря. Code7 исправляет эту воспроизведённую ветку и расширяет диагностику, но ещё NOT_RUN на Honor. P1–P5 не начаты, merge не выполняется.

**P0.6:** первый читаемый символ выравнивается по фактическому viewport; ACK ждёт устойчивой положительной геометрии. После отказа INITIAL/NOTE возобновляется валидированный capture текущего DOM, onPause не переписывает старый якорь как текущий. Трасса schema2 содержит конкретные коды и безопасную геометрию. Рабочий TTS-маршрут не менялся. [Цепочка event47–52, исправление, регрессии и ограничения](docs/P0_6_RESTORE_ACK_REPORT.md).

В существующей диагностике добавлены сохраняемая числовая трасса чтения и явное сравнение двух голосов на current/readest (4 запроса, без кеша/повторов). Обычный маршрут Светланы не менялся. [Факты, изменения, ограничения](docs/P0_5_RESOURCE_STATE_REPORT.md). Предыдущие PASS через fake-порт не считаются подтверждением исправления позиции Honor.

Отдельные полные wire names соответствуют edge-tts; причина отказа Дмитрия ещё не доказана. В диагностике добавлена явная последовательная проверка голосов без кеша, schema 3 считает служебные сообщения и безопасные категории ошибок. Добавлены до трёх отменяемых сетевых попыток на блок и локальная диагностика schema 2 с отдельными событиями синтеза/воспроизведения. Протокол Edge сохранён. [Причины, политика retry и проверки](docs/P0_3_LAYOUT_TTS_REPORT.md).

**P0.2:** исправлены недопустимые CSP-источники для виртуальных имён Readium с подчёркиванием, добавлены единый снимок выделения и восстановление проверенного текстового якоря после готовности DOM. Стартовые события navigator больше не перезаписывают позицию. Шрифт сохраняет верные единицы Readium: 1.0 = 100%. Озвучка сохраняет предел пяти фраз, но получает явные состояния, изолированный prefetch и кнопку «Диагностика TTS» с копированием безопасного отчёта. [Причины шести FAIL и матрица проверок](docs/P0_2_RUNTIME_REPORT.md).

**Исправление P0.1:** SafeHtml получает MIME ресурса; XHTML разбирается и сериализуется как XML с сохранением namespace, XML-экранированием и закрытием пустых тегов. MIME не заменяется на text/html. Проверен результат после настоящей CSS/JS-инъекции Readium 3.4.0. Добавлен Android-тест отображения всех трёх ресурсов и иллюстрации в navigator/WebView, проверки final response и выделения; в облаке он только собран. [Краткий отчёт P0.1](docs/P0_1_XHTML_REPORT.md).

В прототипе: SAF → самостоятельная внутренняя копия EPUB; Readium 3.4.0; вертикальное чтение внутри ресурса и явные переходы между ресурсами; размер шрифта; пробные жёлтые пометки с комментарием и сохранённым DOM-диапазоном; восстановление позиции и черновика; экспериментальный процент последнего видимого символа; два голоса Edge, до пяти фраз, один prefetch, ограниченный кеш и остановка при уходе в фон. Кнопка «Пример P0» импортирует встроенный синтетический EPUB.

**Существенные ограничения:** стабильный Fragment-движок Readium не даёт бесшовной прокрутки и выделения между ресурсами. Его локаторы используют CSS-селектор и текстовый контекст; JJReader дополнительно хранит точный DOM-диапазон и смещения нормализованного текста. Процент и новые пометки блокируются при несовпадении DOM и модели. Первое звучание обоих голосов подтверждено пользователем на Honor, повторные попытки были нестабильны. Их исходную сетевую причину пока нельзя установить по прежнему NETWORK. Прежний cloud CONNECT 403 относится только к сети облака. [Полный отчёт](docs/P0_REPORT.md), [чек-лист Honor](docs/HONOR_CHECKLIST.md).

## Сборка в Windows / PowerShell

Открыть эту папку в Android Studio. Нужны JDK 25, SDK Platform 37 и Build Tools 37.0.0. Версии зафиксированы: AGP 9.4.1, Gradle Wrapper 9.6.0 с SHA-256, Kotlin / Compose compiler 2.4.20, minSdk 31, compileSdk / targetSdk 37. Readium 3.4.0 требует compileSdk 37 и Kotlin 2.4 metadata, поэтому Kotlin обновлён относительно пустого проекта. Остальной исходный стек сохранён. В Android Studio выбрать Gradle JDK 25; существующий `gradle-daemon-jvm.properties` также фиксирует JDK 25.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :edge-protocol:test :app:lintDebug :app:assembleDebugAndroidTest
```

APK: `app\build\outputs\apk\debug\app-debug.apk`. Instrumentation APK: `app\build\outputs\apk\androidTest\debug\app-debug-androidTest.apk`. Для запуска Android-тестов нужен подключённый аппарат или настроенный эмулятор:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

В облаке эти тесты только собраны, запуск **NOT_RUN**. Изолированные тесты используют отдельный каталог и не очищают книги пользователя.

## Подпись и обновление без потери пометок

`applicationId = com.fantadrom.jjreader`, `versionName = 0.1.6-p0`, `versionCode = 7`. Использован тот же debug-ключ среды, что для code 1–6. SHA-256 сертификата:

`06ba3132107a954a4640ad60a29138b297449a6172bb763b8832293dc1c727ef`

Для следующих облачных сборок сохранить `/workspace/android-user/debug.keystore`. Это **debug**, не ключ будущего production-релиза. Ключ не публикуется в Git и не включается в пакет выдачи. Облачные обновления следует собирать в этой же среде с сохранённым ключом. При локальной установке из Android Studio нужно продолжать использовать тот же локальный ключ, которым установлена предыдущая версия.

При локальной сборке Android Studio использует собственный debug-ключ. Если у вас уже есть подходящий ключ с указанным выше отпечатком, перед сборкой можно указать его путь:

```powershell
$env:JJREADER_DEBUG_KEYSTORE = (Resolve-Path "C:\ВашиКлючи\jjreader-debug.keystore").Path
.\gradlew.bat :app:assembleDebug
```

При конфликте подписи не удалять приложение с пометками; вернуться в среду исходной подписи. Для независимой проверки изменённой LGPL-библиотеки можно пересобрать проект со своим debug-ключом и отдельным applicationId, сохранив рабочую установку и её данные.

XML/DOM-регрессия запускается после JVM-тестов: они создают `app/build/xhtml-regression` из реального SafeHtml и injector из AAR Readium. Robolectric 4.16.1 / API 35 нужен для Android Uri внутри injector, его кеш изолирован в `work/`; это JVM-проверка, не Android WebView runtime. Для Node нужны зависимости из `tools/package-lock.json` и путь к `readium-reflowable.js` именно из AAR 3.4.0:

```powershell
npm ci --prefix tools
node tools\verify_dom.cjs "C:\Путь\readium-reflowable.js"
```

## Устройство исходников и данных

- `books/`: атомарный импорт, UUID внутренней книги, проверка ZIP без распаковки на диск.
- `engine/`: Readium, фильтрация HTML, мост DOM ↔ локатор. `assets/locator-bridge.js` не открывает Java-интерфейс книге.
- `text/`: каноническая модель v1 и счётчик Unicode code points.
- `notes/`: версия схемы 1, AtomicFile для пометок, черновика, позиции и размера шрифта.
- `tts/`: прямой WebSocket, сегментация, MediaPlayer, аудиофокус, отмена и поколение запуска.
- `edge-protocol/`: изолированная Java-библиотека Sec-MS-GEC v2, LGPL-3.0-or-later.

Данные: `files/books-v1/<UUID>/book.epub`, `book.json`, `reader.json`; текущая книга — `files/books-v1/current.json`. EPUB остаётся неизменной копией. Представление HTML фильтруется в памяти: скрипты книги и внешние ресурсы отключены; DRM, включая обфусцированные шрифты с encryption.xml, и fixed layout отклоняются. В P0 каждый импорт получает новый ID. Предыдущие каталоги сохраняются, интерфейса полки и дедупликации ещё нет. Не применять очистку данных приложения между проверками. P1 должен сохранить эту схему или явно мигрировать её.

Нормализация: порядок spine, без разметки, nav, script/style, hidden/aria-hidden, SVG/math и alt. ASCII-пробелы и NBSP схлопываются в один пробел; блочные границы — два LF; хвостовые пробелы/LF удаляются. Без NFC-преобразования; code points не смешиваются с UTF-16 DOM offset. Границы якорей расширяются до grapheme через Intl.Segmenter. При его отсутствии сложные составные символы требуют отдельной проверки. Разделители между ресурсами в счётчик не добавляются. CSS-скрытый издателем текст пока может учитываться: это ограничение P0.

Полной полки, жестов/яркости/тем, полноценных цветовых пометок, экспорта DOCX, плеера P4 и приёмки P5 нет.

## Данные и проверки P0.2

В `reader.json` добавляется `positionV2` с ID книги/ресурсом, диапазоном code points, цитатой и hash. Первые события navigator не пишут поверх него. После проверки правильного DOM выполняется переход и проверка видимости; запись позиции разрешается только затем. Во время IME/редактора запись заморожена. Старые пометки, черновики и доступный legacy DOM range сохраняются; уже не записанный старой версией диапазон восстановить из отсутствующих данных невозможно.

`fontUnits=readium-scale-v1` явно помечает прежнюю шкалу без умножения на 100. Кеш содержит максимум 12 MP3; диагностика различает cache/network и сохраняет только разрешённые метаданные. Endpoint и сообщения Edge-протокола прежние.

`tools/verify_browser_runtime.cjs` принимает каталог `assets`, извлечённый из AAR Readium 3.4.0, путь к установленному Chromium и каталог результатов с синтетической `diagram.png` из примера. Он проверяет реальную CSS-геометрию/CSP в настольном Chromium; Java callbacks замещены, это не Android runtime. Native `ReaderRuntimeTest` использует настоящую P0 Activity в изолированном каталоге: long-press/ActionMode, шрифт, пометки, черновик, recreate, orientation и видимость декорации. Необязательный разработческий `tools/android_process_restart.ps1` выполняет две instrumentation-фазы с force-stop и проверкой нового PID, без очистки данных. Для обычной обратной связи ADB не нужен: «Диагностика TTS» → «Копировать».
