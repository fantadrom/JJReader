# JJReader · P0 / 0.1.0-p0

Android-прототип для проверки EPUB и Edge TTS. Основа — существующий проект `fantadrom/JJReader`, исходный commit `62bac7e`. Реализован только P0. Приёмка на Honor ABR-LX1 / Android 15 ещё не выполнена; к P1 автоматически не переходим.

В прототипе: SAF → самостоятельная внутренняя копия EPUB; Readium 3.4.0; вертикальное чтение внутри ресурса и явные переходы между ресурсами; размер шрифта; пробные жёлтые пометки с комментарием и сохранённым DOM-диапазоном; восстановление позиции и черновика; экспериментальный процент последнего видимого символа; два голоса Edge, до пяти фраз, один prefetch, ограниченный кеш и остановка при уходе в фон. Кнопка «Пример P0» импортирует встроенный синтетический EPUB.

**Существенные ограничения:** стабильный Fragment-движок Readium не даёт бесшовной прокрутки и выделения между ресурсами. Его локаторы используют CSS-селектор и текстовый контекст; JJReader дополнительно хранит точный DOM-диапазон и смещения нормализованного текста. Процент и новые пометки блокируются при несовпадении DOM и модели. Это требует проверки в настоящем WebView. Edge в облачной среде блокируется прокси до соединения с Microsoft (`CONNECT 403`); голоса не объявлены проверенными. [Полный отчёт и таблица](docs/P0_REPORT.md), [чек-лист Honor](docs/HONOR_CHECKLIST.md).

## Сборка в Windows / PowerShell

Открыть эту папку в Android Studio. Нужны JDK 25, SDK Platform 37 и Build Tools 37.0.0. Версии зафиксированы: AGP 9.4.1, Gradle Wrapper 9.6.0 с SHA-256, Kotlin / Compose compiler 2.4.20, minSdk 31, compileSdk / targetSdk 37. Readium 3.4.0 требует compileSdk 37 и Kotlin 2.4 metadata, поэтому Kotlin обновлён относительно пустого проекта. Остальной исходный стек сохранён. В Android Studio выбрать Gradle JDK 25; существующий `gradle-daemon-jvm.properties` также фиксирует JDK 25.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :edge-protocol:test :app:lintDebug :app:assembleDebugAndroidTest
```

APK: `app\build\outputs\apk\debug\app-debug.apk`. Instrumentation APK: `app\build\outputs\apk\androidTest\debug\app-debug-androidTest.apk`. Для запуска Android-тестов нужен подключённый аппарат или настроенный эмулятор:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

В облаке эти тесты только собраны, запуск **NOT_RUN**. Изолированные тесты используют отдельный каталог и не очищают книги пользователя.

## Подпись и обновление без потери пометок

`applicationId = com.fantadrom.jjreader`, `versionName = 0.1.0-p0`, `versionCode = 1`. Использован уже существующий debug-ключ среды. SHA-256 сертификата:

`06ba3132107a954a4640ad60a29138b297449a6172bb763b8832293dc1c727ef`

Для следующих облачных сборок сохранить `/workspace/android-user/debug.keystore`. Для локальной пересборки приложен отдельный архив тестового ключа. Это **debug**, не ключ будущего production-релиза. Он не публикуется в Git. Распаковать его в `.local\jjreader-debug.keystore` и перед сборкой указать:

```powershell
$env:JJREADER_DEBUG_KEYSTORE = (Resolve-Path ".\.local\jjreader-debug.keystore").Path
.\gradlew.bat :app:assembleDebug
```

Обычный локальный debug-ключ Android Studio может отличаться от облачного. При конфликте подписи не удалять приложение с пометками; собрать обновление тем же ключом или вернуться в среду исходной подписи. Для тестового LGPL-пересобирания можно использовать другую подпись в отдельном тестовом профиле устройства, сохранив рабочую установку и её данные.

## Устройство исходников и данных

- `books/`: атомарный импорт, UUID внутренней книги, проверка ZIP без распаковки на диск.
- `engine/`: Readium, фильтрация HTML, мост DOM ↔ локатор. `assets/locator-bridge.js` не открывает Java-интерфейс книге.
- `text/`: каноническая модель v1 и счётчик Unicode code points.
- `notes/`: версия схемы 1, AtomicFile для пометок, черновика, позиции и размера шрифта.
- `tts/`: прямой WebSocket, сегментация, MediaPlayer, аудиофокус, отмена и поколение запуска.
- `edge-protocol/`: изолированная Java-библиотека Sec-MS-GEC v2, LGPL-3.0-or-later.

Данные: `files/books-v1/<UUID>/book.epub`, `book.json`, `reader.json`; текущая книга — `files/books-v1/current.json`. EPUB остаётся неизменной копией. Представление HTML фильтруется в памяти: скрипты книги и внешние ресурсы отключены; DRM, включая обфусцированные шрифты с encryption.xml, и fixed layout отклоняются. В P0 каждый импорт получает новый ID. Предыдущие каталоги сохраняются, интерфейса полки и дедупликации ещё нет. Не применять очистку данных приложения между проверками. P1 должен сохранить эту схему или явно мигрировать её.

Нормализация: порядок spine, без разметки, nav, script/style, hidden/aria-hidden, SVG/math и alt. ASCII-пробелы и NBSP схлопываются в один пробел; блочные границы — два LF; хвостовые пробелы/LF удаляются. Без NFC-преобразования; code points не смешиваются с UTF-16 DOM offset. Границы якорей расширяются до grapheme через Intl.Segmenter. При его отсутствии сложные составные символы требуют отдельной проверки. Разделители между ресурсами в счётчик не добавляются. CSS-скрытый издателем текст пока может учитываться: это ограничение P0.

Полной полки, жестов/яркости/тем, полноценных цветовых пометок, экспорта DOCX, плеера P4 и приёмки P5 нет.
