# Honor — P1.1 / 0.2.1-p1 / code12

Установить **обновлением поверх code11**, без удаления приложения, очистки данных и переимпорта. Прежние пункты1–4 и6–8 P1 подтверждены пользователем; эта сборка P1.1 на Honor **NOT_RUN**. [Отчёт P1.1](P1_1_TAP_BOUNDARIES_REPORT.md), [актуальное ТЗ](JJReader_TZ.md). PR#2 остаётся Draft до приёмки.

1. **Правый тап:** последняя строка целиком видна и ниже хотя бы одна обычная строка пустого места → одним правым касанием открыть следующий раздел. Частичная последняя строка/меньше строки запаса → сначала обычное перемещение. Уже прокрученный пустой хвост не требует возвращать текст в экран. Последний раздел не зацикливается; процент остаётся100% на последнем символе.
2. **Левый тап:** из показанного начала с естественными полями или выровненным заголовком сразу открывается заполненный заключительный экран предыдущего с запасом min(четыре строки,половина области чтения). Нет промежуточных экранов с одними полями/единственной строкой. Ещё одно левое касание листает назад с перекрытием строки. Короткий ресурс остаётся у начала; первая граница безопасна.
3. **Начало и сохранение:** новый раздел открывается с небольшим естественным верхним отступом без позднего скачка заголовка. Сразу после входа в начало и в конец по левому тапу выполнить поворот/перезапуск, шесть поворотов, смену шрифта/размера и скрытие/показ панелей. Способ размещения сохраняется без дрейфа. После обычной прокрутки сохраняется уже новое место. Проверить пометка x1 → поворот → пометка x2 другого ресурса → поворот.
4. **Медиа/жесты:** обложка перед заголовком не пропускается; иллюстрация/таблица/подпись после текста не пропускаются правым тапом. Для высокой картинки видна нижняя часть с запасом; пустой/image-only ресурс доступен отдельно. Обратный вертикальный жест по-прежнему открывает конец около верха. Выделение/его отмена, ссылки, пометки и яркость в левых10% не запускают побочный переход.
5. **Ориентации/TTS/отмена:** повторить основные переходы в landscape, крупным шрифтом и со скрытыми панелями. Быстрые касания, Home, смена книги и переход по пометке не приводят к позднему прыжку назад. Обычные пять фраз TTS проходят ресурс; ручной боковой тап сбрасывает очередь, автоматический переход TTS её сохраняет. Старые книги/ID/пометки/черновики и настройки доступны.

В выдаче есть синтетический `JJReader-P1.1-taps.epub` с длинным/коротким текстом, обложкой, завершающей иллюстрацией/таблицей, пустым ресурсом. Для сообщения о сбое достаточно версии, номера пункта и диагностики из меню; личный EPUB/комментарии присылать не требуется. P2–P5 не начинать по этому чек-листу.
