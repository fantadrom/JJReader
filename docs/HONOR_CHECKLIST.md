# Honor — P1 / 0.2.0-p1 / code11

Установить обновлением поверх принятого P0.8, без удаления приложения, очистки данных или повторного импорта. P0 принят пользователем; **эта сборка P1 на Honor NOT_RUN**. [Отчёт](P1_READER_SHELF_REPORT.md), [актуальное ТЗ](JJReader_TZ.md).

1. **Старые данные:** на полке видны прежние копии/ID и количества пометок. Открыть книгу, проверить старую пометку/комментарий/черновик. Переключить две книги на разные места, вернуться и перезапустить. Исторический процент, которого P0 не сохранял, появится после открытия; место не должно теряться.
2. **SAF:** выбрать стартовую папку, открыть подпапку/EPUB. Отменить выбор новой папки/файла — данные прежние. Перезапустить: папка доступна, если провайдер разрешил удержание доступа. Переместить исходный файл или отозвать доступ к папке: внутренняя книга продолжает открываться, ошибка папки понятная. Повторный идентичный EPUB не создаёт копию; несколько старых совпадений дают выбор.
3. **Подтверждения:** на тестовой копии «Действия → Очистить пометки», сначала отменить. Затем подтвердить: notes/черновик исчезли, место/шрифт/книга сохранены. «Удалить книгу» сначала отменить, затем подтвердить на ненужной тестовой копии: исчезает только она, SAF-оригинал и другая книга остаются.
4. **Панели/положение:** центральное касание скрывает и показывает панели. Повторить шесть раз возле конца раздела, затем x1 → поворот → x2 другого ресурса → поворот, шесть поворотов и Home/блокировку/перезапуск. Нет возврата к старому разделу и накопительного дрейфа. В landscape текст полный по ширине.
5. **Жесты:** вне левых10% обычная прокрутка; достичь края без автоматического перехода, следующий жест меняет ресурс. В левой полосе движение меняет только яркость окна: не прокручивает и не переключает ресурс даже у края. Долгий тап/маркеры выделения, ссылки и пометки имеют приоритет. Боковые касания листают с перекрытием строки; центр переключает только панели.
6. **Навигация:** общий ползунок → середина/конец → «Вернуться». TOC/старая пометка → «Вернуться». Быстро перетаскивать ползунок: остаётся последнее место, нет последующей серии прыжков. Хвост не увеличивает процент, последний видимый символ даёт100%; image-only ресурс восстанавливается без фиктивной цитаты.
7. **Оформление:** дневная/ночная/авто, три семейства шрифта и размер. То же место и настройки после рестарта. В landscape настройки прокручиваются. Яркость не меняет системную настройку других приложений. Если меняется системная тема с открытым черновиком, он сохраняется.
8. **Ссылки и TTS:** обычная сноска/ссылка и явный возврат сохранены (в выдаче есть синтетический P0.8 EPUB). Пять фраз проходят ресурс с подсветкой. Пауза/продолжение работают; ручной переход сбрасывает старую очередь. После меню/полки/изменения вёрстки продолжать вручную; после пересоздания Activity можно заново запустить пять фраз. Полный плеер/экспорт/цветовые пометки не проверять как готовые P1-функции.

При сбое: версия, номер пункта, что произошло, одна копия диагностики из меню. Личный EPUB/текст присылать не требуется. P2 запускается отдельным поручением после результатов P1.
