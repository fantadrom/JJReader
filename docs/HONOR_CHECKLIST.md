# Honor — P0.8 / 0.1.9-p0 / code10

Установить поверх code9 без удаления, очистки данных и переимпорта прежней книги. В диагностике должна быть 0.1.9-p0/code10 и новый основной режим **sections**. Code10 Honor NOT_RUN. [Отчёт](P0_8_SECTION_NAVIGATION_REPORT.md).

1. **Прежние книги:** «Книги» → выбрать старую копию по числу пометок/ID. Проверить цитаты, комментарии, переход и место. Открыть другую запись и вернуться; перезапустить приложение.
2. **Повторный EPUB:** выбрать тот же файл через «Открыть EPUB». Один дубль открывается сразу, несколько дают выбор. Нет лишней копии; пометки сохранены. Проверить отмену. «Пример P0» тоже переиспользует копию.
3. **Край:** поднять последнюю строку к верху. Достижение края не переключает раздел; следующий отдельный жест вверх открывает следующий с начала. В начале жест вниз возвращает к концу предыдущего. Проверить короткий раздел, первую/последнюю границы. Кнопки обоих направлений ведут к началу.
4. **Выделение и позиция:** пометка рядом с краем; x1 → поворот → x2 другого раздела → поворот. Затем шесть поворотов, шрифт, Home/блокировка и перезапуск, включая последнюю строку. Нет ухода к x1/дрейфа.
5. **Landscape/содержимое:** полная ширина после жестов/кнопок/TOC. Проверить картинку, внутреннюю ссылку/сноску и явный возврат. В выдаче есть JJReader-P0.8-sections.epub с иллюстрацией, пустым/коротким разделами и ссылкой «Вернуться к вызову». Процент не растёт от пустого хвоста, EOF последнего текста — 100%.
6. **5 фраз:** запуск перед стыком автоматически открывает следующий документ, продолжает звук и подсветку. Пауза/ручное продолжение, Home/блокировка. Ручной переход к пометке/TOC/кнопкой/жестом сбрасывает очередь; «Продолжить» не возвращает назад.
7. **Большая книга:** сравнить открытие, кнопки/краевой жест/шрифт с unified через «Диагностика TTS → Проверки → Режим». Выбор unified после первой миграции сохраняется; вернуться в sections можно пунктом «Прежний режим по разделам». Указать заметные задержки; количественные команды в отчёте.

При сбое сразу скопировать общую диагностику и указать номер пункта/что произошло. Не повторять сбой по кругу. Непроверенные картинки/сноски не отмечать PASS. P0 в целом и P1 пока не принимаются автоматически.
