# Honor — P0.4 / 0.1.4-p0 / code 5

Новая версия на Honor **NOT_RUN**. Обновить поверх прежней облачной установки, без удаления, очистки или переимпорта. Подпись прежняя. Результаты code 4 сохранены в [отчёте](P0_4_POSITION_VOICE_REPORT.md).

1. Перейти через список к пометке x1 → повернуть → перейти к пометке x2 в другом разделе → сразу повернуть. Остаётся x2. Повторить несколько раз; отдельно подождать 2–3 секунды перед поворотом. После перехода x2 закрыть/перезапустить приложение: остаётся тот же раздел, приблизительное место допустимо.
2. Проверить сохранённый размер шрифта, пометки и ширину landscape. Кнопки чтения остались прежними.
3. Открыть «Диагностика TTS» → «Проверить голоса». Приложение отправит Microsoft только показанную фиксированную фразу «Проверка голоса. Сегодня ясный день.», сначала Дмитрием, затем Светланой, без кеша и prefetch, по одной попытке. Дождаться обоих результатов, затем «Копировать». Не требуется много повторных запусков. purpose=voiceCheck, source=network, maxAttempts=1 для каждого голоса.
4. Если Дмитрий синтезировал контрольную фразу, проверить обычные пять фраз книги и подсветку. Проверить, что Светлана продолжает работать. Отличать synthesis=success от playback=completed, cache от network; config/ssmlSendAccepted означают только очередь отправки. При отказе нужны textMessages/binaryMessages/paths, audioBytes/audioFrames, protocolError/category и code.
5. Во время запроса/звука проверить Пауза, затем Home/блокировку. Звук не включается сам после возврата. Обычную озвучку продолжать вручную; контрольная проверка не возобновляется автоматически.

В обратной связи: code 5, номер пункта, PASS/FAIL и скопированная безопасная диагностика. Отказ Дмитрия в code 4 не объявлен неподдерживаемым голосом; новый формат ещё требует реальной проверки. P1–P5 автоматически не начинаются.
