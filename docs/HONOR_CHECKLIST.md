# Ручная приёмка P0: Honor ABR-LX1 / Android 15

Статус всех пунктов до проверки пользователем: **NOT_RUN**. Устанавливать `JJReader-0.1.0-p0-debug.apk`; не очищать данные и не удалять приложение с пометками. При несовместимой подписи сначала свериться с README.

1. **Иконка и запуск.** Проверить домашний экран, список приложений и системную заставку. Ожидается табличка с синим/красным светом, видимый сколотый край, без стандартного Android-рисунка; нет отдельного экрана с задержкой. Круглая маска не обрезает табличку. Логотип Fantadrom в интерфейсе отсутствует.
2. **Импорт и чтение.** Нажать «Пример P0», затем отдельно открыть внешний EPUB через «Открыть EPUB». Ожидается заголовок книги и вертикальная прокрутка; отмена системного выбора сохраняет текущую книгу. После импорта переместить исходный внешний файл: внутренняя копия продолжает открываться без интернета. Повреждённый/DRM/fixed-layout файл получает сообщение, предыдущая книга остаётся доступна.
3. **Одинаковые слова.** В примере выделить первое «маяк» в абзаце «Контрольное первое вхождение», выбрать «Пометка», ввести «первое», сохранить. Создать вторую пометку у «Контрольное второе вхождение». Ожидаются две жёлтые пометки и точки в поле; точка не закрывает буквы. Сохранение — одним нажатием, клавиатура при вводе открывается сразу.
4. **Шрифт / поворот / перезапуск.** Нажать «А+» трижды, повернуть устройство, закрыть приложение, остановить его через настройки Android и открыть снова. Нажать «Пометки» и обе записи по очереди. Ожидается переход к соответствующему первому/второму вхождению, не к случайному совпадению; количество и комментарии сохраняются. Позиция чтения сохраняется по тексту.
5. **Черновик.** Начать ещё одну пометку, ввести текст, уйти в фон и остановить процесс через настройки Android. Открыть приложение. Ожидается восстановление несохранённого комментария; «Отменить» удаляет только этот черновик. Существующие пометки остаются.
6. **Границы / Unicode / процент.** Выделить несколько строк, расширить выделение за экран; проверить emoji и «ё». У конца первого ресурса видна строка «КОНЕЦ ПЕРВОГО РЕСУРСА»; «Раздел →» показывает «НАЧАЛО ВТОРОГО РЕСУРСА». Проверить аналогично второй/третий. Переходы явные: бесшовная прокрутка и выделение между ресурсами не поддерживаются выбранным стабильным navigator. В конце последнего читаемого символа ожидается 100%; до конца — не 100%. Изменение видимой области может изменить процент последнего видимого символа, но не должно увести позицию чтения.
7. **Оба голоса.** Включить интернет, выбрать «Дмитрий», нажать «5 фраз» и подтвердить отправку фраз Microsoft. Ожидаются реальные аудио, последовательные фразы и синее подчёркивание звучащей фразы. Повторить со «Светланой». Облачная проверка заблокирована `CONNECT 403`, поэтому результат на Honor нужно записать отдельно. При ошибке записать показанный код; чтение и пометки должны продолжать работать.
8. **Остановка звука.** Во время речи нажать Home, затем отдельно заблокировать экран, затем начать выделение. Каждый раз звук прекращается. Возвращение/разблокировка/закрытие выделения не запускают его. «Продолжить» запускает текущую пробную фразу вручную с её начала. Смена голоса или книги отменяет старую очередь; сначала снова нажать «5 фраз».

Для обратной связи достаточно: модель/версия Android, номер пункта, PASS/FAIL, показанный код ошибки и короткое описание. Особенно нужны результаты пунктов 1, 4, 6–8. Содержимое личной книги в диагностические логи отправлять не требуется. После этой проверки отдельно решаем, подходит ли Readium с границами ресурсов; P1 в данном задании не запускается.
