# Honor — P0.3 / 0.1.3-p0 / code 4

Code 4 на устройстве **NOT_RUN**. Ручные подтверждения code 3 и диагностический пример сохранены в [отчёте P0.3](P0_3_LAYOUT_TTS_REPORT.md). Обновить поверх прежней облачной версии без удаления/очистки данных: подпись прежняя, книги и пометки сохраняются.

1. Открыть пример/книгу. Portrait → landscape → portrait: текст использует ширину с обычными небольшими полями, место примерно сохранено. Кнопки остались прежними.
2. Изменить размер шрифта; проверить сохранённую пометку после поворота.
3. На новом фрагменте запустить пять фраз Дмитрием, затем Светланой. Проверить подсветку. При временном сбое уже прочитанные фразы не повторяются.
4. При сетевом отказе дождаться ограниченного результата (до 3 попыток) и нажать «Диагностика TTS» → «Копировать». В schema 2 сравнить source cache/network, block, networkAttempt/maxAttempts, openedMs, firstAudioMs, audioBytes/audioFrames, synthesizedMs и playbackMs/completedMs. Cache не подтверждает сетевой успех. Не требуется много слепых перезапусков: после ошибки «Продолжить» повторяет непрочитанную фразу.
5. Во время сети/«Повтор подключения N/3» нажать паузу, затем отдельно Home/блокировку. Звук не включается сам; после возврата продолжить вручную.

В обратной связи указать code 4, номер пункта, PASS/FAIL и безопасную диагностику при сбое. Непрерывная прокрутка/выделение через ресурсы остаются отдельным вопросом перед P1. P1–P5 не начинаются автоматически.
