# Honor — короткая проверка P0.2 / 0.1.2-p0 / code 3

Прежние PASS/FAIL code 2 сохранены в [отчёте](P0_2_RUNTIME_REPORT.md). Пункты ниже для code 3 пока **NOT_RUN**. Обновить без удаления и очистки данных. Если предыдущая установка собрана в Android Studio, использовать тот же локальный ключ; облачный APK имеет прежнюю облачную подпись.

1. В «Примере P0» нажать А+ три раза, затем А−. Ожидается явное изменение размера без ухода к началу раздела.
2. Сделать комментарии на первом и втором контрольном вхождении «маяк». Ожидается счётчик 2, сохранённые комментарии и переход к соответствующему вхождению, включая возврат после изменения шрифта.
3. Прокрутить в середину длинного раздела и дождаться обновления процента. Повернуть экран; затем удалить приложение из недавних и открыть; отдельно выполнить force-stop через настройки Android и открыть. Ожидаются тот же текст и обе пометки. Записать, какой из трёх сценариев проверен. Home/блокировка с обычным возвратом — отдельный ранее пройденный сценарий.
4. Начать ещё один комментарий, ввести черновик, прервать приложение/повернуть. Ожидается восстановление черновика; его отмена сохраняет обе прежние пометки и место чтения.
5. Для каждого голоса проиграть до пяти фраз. Ожидается видимое синее подчёркивание текущей фразы. После завершения снова нажать «5 фраз». «Продолжить» завершённой очереди сообщает о необходимости нового запуска; пустая очередь не молчит. Проверить cache/network в диагностике отдельно: кеш не доказывает доступность сети.
6. Проверить паузу/продолжение, Home, блокировку экрана, начало выделения, смену голоса и книги. Ожидается остановка без самопроизвольного возобновления или старых фраз. Остановку звука при Home/блокировке нужно подтвердить отдельно от сохранения позиции.
7. При тишине/ошибке нажать «Диагностика TTS» → «Копировать». Отчёт содержит ID, этап, категорию/HTTP/close code, cache/network и классы причин, без текста книги. Указать, нажимали «5 фраз» или «Продолжить», был ли голос уже завершён, какая сеть доступна. После возврата интернета новый явный запуск должен оставаться доступен; чтение/пометки работают без сети.

В обратной связи: номер пункта, PASS/FAIL, версия приложения и текст безопасной диагностики при проблемах TTS. Полной настройки ADB для этого не требуется. P1–P5 автоматически не запускаются.
