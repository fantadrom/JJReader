# Honor — P2 / 0.3.0-p2 / code13

Установить **обновлением поверх code12**, без очистки данных и переимпорта. P1.1 принят пользователем; эта сборка P2 на Honor **NOT_RUN**. [Отчёт](P2_NOTES_CONTEXT_REPORT.md), [ТЗ](JJReader_TZ.md). P3–P5 не начинать; PR P2 не сливать до приёмки.

1. **Прежние данные:** открыть старую книгу. Цитаты/комментарии и места прежних пометок совпадают; их жёлтый цвет сохранён. Изменить комментарий/цвет одной старой пометки: ID/количество и привязка не меняются. Пометка x1 → поворот → x2 другого ресурса → поворот; проверить Home/перезапуск и черновик.
2. **Создание и редактирование:** выделение → «Цвет» → один из пяти подписанных цветов без комментария. Выделение → «Пометка» открывает цитату, курсор и клавиатуру; один Save. В редакторе добавить/сменить/снять цвет при сохранённом тексте; пустой текст без цвета не сохраняется. Закрыть редактор Back с недописанным текстом: «Пометки → Продолжить черновик», затем перезапуск/поворот — текст сохранён. Новая пометка не должна молча заменять другой черновик.
3. **Пересечения/удаление:** создать одинаковые слова в разных местах и две пересекающиеся/совпадающие пометки. Нажатие на пересечение даёт выбор; все записи остаются отдельно. Значок есть у текстового комментария, не у чистого цвета. Удалить одну запись и отменить удаление; после перезапуска проверить восстановление. Очистку всех пометок проверять только на ненужной копии с подтверждением.
4. **Контекст:** в меню «Пометки» менять N (по умолчанию350), переключать «Пометки / Контексты». Проверить несколько абзацев с обеих сторон, длинный абзац, Unicode/emoji, начало/конец главы. В поставке есть `JJReader-P2-logical.epub`: Альфа занимает r0 и начало r1; Бета начинается внутри r1 и продолжается в r2. У пометки в конце r0 контекст проходит в Альфу r1, но не в Бету. Возле границы Беты контекст не берёт Альфу. Повторное открытие сохраняет N; другая книга имеет своё N.
5. **Группы и список:** цепочка близких пометок объединяется, нумерация связана с цитатами/комментариями. Простое пересечение пустых контекстов не объединяет отдалённые выделения; разные логические главы не объединяются. Несколько комментариев к одному диапазону остаются. «Читать» → место и «К пометкам» → список. В landscape/ночной теме все цвета, текст и настройки читаемы; клавиатура N не меняет место чтения.
6. **Кадр перехода:** из начала ресурса левый тап открывает заключительный экран предыдущего с запасом min(4L,H/2). Начало предыдущего документа не мелькает: допустим короткий экран «Открытие раздела…». Проверить быстрые тап/назад-вперёд, поворот и Home в момент перехода. В диагностике порядок: PRESENT_HIDE → ACK → PRESENT_VISUAL_READY → PRESENT_REVEAL; stale/cancel не должны открывать старый документ. Если сбой — прислать диагностику, не текст книги.
7. **Регрессия:** правильный правый тап на содержательном конце, прежний обратный вертикальный жест, ссылки/сноски/возврат, яркость, шрифты/панели/шесть поворотов без дрейфа, 100% без хвоста, независимые позиции двух книг, пять фраз TTS и ручной сброс очереди. На полке «Действия → Пометки и контексты» позволяет читать сохранённые замечания даже при недоступном EPUB; переход к тексту требует открытой книги.

Полноценный DOCX и копирование всего отчёта пока не проверять как готовые функции: это P3. Если TOC не даёт однозначных границ или EPUB утрачен до построения карты, список явно использует «Ресурс: …». Источник не изменяется; удаление внутренней книги пользователем очищает и карту/пометки.
