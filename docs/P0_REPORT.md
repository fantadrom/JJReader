## Что подготовлено

SAF и атомарная внутренняя копия; Readium 3.4.0 с вертикальным режимом; размер шрифта; пробные жёлтые комментарии, черновик, список и переход; сохранение JSON схемы v1 через AtomicFile; модель текста в порядке spine; экспериментальный процент последнего видимого символа; значок в поле; прямой Edge WebSocket для Дмитрия/Светланы; максимум пять фраз, один prefetch, ограниченный MP3-кеш, MediaPlayer, аудиофокус, остановка/отмена при уходе в фон. Текст и аудио не пишутся в диагностические логи. Перед первой озвучкой есть пояснение об отправке выбранных фраз Microsoft.

Синтетический EPUB: три ресурса, русский текст, повторяющееся «маяк» в одном/разных абзацах и главах, длинные/короткие абзацы, инициалы/сокращения/диалог, combining marks, emoji, иллюстрация и контрольные строки на границах. Личные литературные материалы не использовались.

Иконка подготовлена из исходного изображения без перерисовки: PNG пяти плотностей, adaptive icon с тёмным фоном; изображение масштабировано пропорционально с полями. Старые Android launcher-ресурсы удалены. Fantadrom logo не включён в интерфейс/ресурсы APK. Системная заставка использует эту же иконку без дополнительной задержки.

## Вывод по основе и ограничения

Readium 3.4.0 пригоден как готовая основа прототипа с вертикальной прокруткой **внутри ресурсов**. Он не удовлетворяет буквальному обязательному требованию бесшовного перехода между ресурсами. Это существенное архитектурное ограничение для P1, а не исправленный баг. До начала P1 нужно проверить Honor и отдельно принять границы ресурсов либо сменить navigator/движок. Не выдаём поиск цитаты за доказательство точной привязки: точный диапазон хранится отдельно, CSS-selector с полным контекстом передаётся Readium, DOM дополнительно проверяется по модели.

Новый Compose navigator Readium 3.4.0 остаётся experimental; по официальной таблице не даёт CSS-selector в selection и имеет другие пробелы. Он не подключён скрытно вместо стабильного. Если бесшовность обязательна без уступок, конкретный кандидат на отдельную проверку — foliate-js (MIT, лицензия проверена). Его Android-встраивание в этом P0 не выполнялось. Бесконечное сравнение движков не проводилось.

Другие ограничения P0: каждый импорт — новый ID, нет полки/дедупликации; предыдущие каталоги не удаляются. HTML обрабатывается в UTF-8; сложная издательская CSS-скрытость пока не полностью отражена в текстовой модели. EPUB с encryption.xml, включая обфусцированные шрифты, отклоняется. Процент требует настоящей WebView-проверки на иллюстрациях/длинных абзацах. Крупный роман, пересечения пометок и полный экспорт не приняты. Пробное TTS не обещает полный набор правил русской пунктуации, точное возобновление аудиосэмпла, управление 20+ фразами и настройку скорости; это P4.

Оригинальный debug-ключ среды использован повторно. Отличие локального ключа и способ пересборки без удаления данных описаны в README. Фактический APK, его хеш, commit и Draft PR записаны в DELIVERY.json. Следующий шаг — [чек-лист Honor](HONOR_CHECKLIST.md), особенно иконка, повторяющиеся слова, границы ресурсов и оба голоса. P1–P5 не начаты.
